# M07 architecture references

These six author-supplied images are **architecture only**: visual references for pale stone, orthogonal forms, terraces, arcades, planted public spaces and fountains. They are **not geographic/cartographic authority and not sources of new plot or spatial facts**. The [written descriptive standard](../../live-model/22_CIVILIZATION_AND_WILDS.md#milestone-07-ordinary-city-architecture) controls which details apply. Existing pixel maps retain route/location authority; no apartment, city identity, road, canal, mountain or palace is established by these pictures.

Incidental details are not blanket canon: the pedestrian-plaza image includes pitched roof forms, and city views include monumental skylines and abundant water. These do not override the flat-roof/usual 2–4 occupied-story standard or the requirement that waterways be mapped. No rendering trials, layer screenshots, map-drawing instructions, procedural cartography recommendations or new maps are included.
